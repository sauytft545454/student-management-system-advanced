# Advanced Student Management System (SQL Project)

This project is built using MySQL and demonstrates a real-world relational database system.

## 📌 Features
- 7 Tables (Departments, Students, Instructors, Courses, Enrollments, Marks, Attendance)
- Primary & Foreign Key relationships
- Many-to-Many relationships
- INNER JOIN operations
- GROUP BY and filtering queries

## 🧠 Concepts Used
- Relational Database Design
- SQL Joins
- Aggregation Functions
- Data Relationships

## 📊 Sample Queries
- Student marks with course
- Students with low attendance
- Number of students per course

## ▶️ How to Run
1. Open MySQL
2. Run database.sql
3. Execute queries
